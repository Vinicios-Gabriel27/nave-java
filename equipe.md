# 🚀 Missão Marte

Projeto desenvolvido em Java como parte da disciplina de Programação Orientada a Objetos.

O jogo simula uma missão espacial em Marte, onde o jogador controla uma nave e precisa cumprir os desafios da missão.

## 🎮 Sobre o projeto

O projeto consiste em um jogo de console desenvolvido utilizando a linguagem Java.

Durante o jogo, o jogador pode:

- Iniciar uma missão;
- Controlar a nave;
- Movimentar-se pelo mapa;
- Transportar passageiros;
- Encontrar obstáculos e inimigos;
- Enfrentar asteroides;
- Definir diferentes níveis de dificuldade;
- Gerar missões;
- Consultar o ranking dos jogadores.

## 📁 Estrutura do projeto

As principais classes do projeto são:

- `Main.java` — inicia o programa.
- `Jogo.java` — controla o funcionamento principal do jogo.
- `Menu.java` — exibe as opções do jogo.
- `Mapa.java` — controla o mapa da missão.
- `Nave.java` — representa a nave espacial.
- `Missao.java` — controla os elementos da missão.
- `GeradorMissao.java` — gera as missões.
- `Asteroide.java` — representa os asteroides.
- `Inimigo.java` — representa os inimigos.
- `Astronauta.java` — representa o astronauta.
- `Engenheiro.java` — representa o engenheiro.
- `Professor.java` — representa o professor.
- `Passageiro.java` — representa os passageiros.
- `Dificuldade.java` — controla os níveis de dificuldade.
- `Ranking.java` — controla o ranking dos jogadores.
- `RankingEntry.java` — representa uma entrada do ranking.

## ▶️ Como executar

1. Abra o projeto no IntelliJ IDEA.
2. Configure o JDK.
3. Abra a classe `Main.java`.
4. Execute o método `main`.
5. Siga as instruções apresentadas no console.

## 💾 Ranking

O jogo possui um sistema de ranking para armazenar os resultados dos jogadores.

Os dados do ranking são armazenados em um arquivo JSON.

## 🎯 Objetivo

O objetivo do projeto é aplicar conceitos de Programação Orientada a Objetos na construção de um jogo em Java, utilizando classes, objetos, métodos, encapsulamento, herança e organização do código.
